# Приглашения на 17 октября

Два артефакта под две аудитории.

```
card/                картинка на венчание — HTML-шаблон + рендер в PNG 1080×1350
site/index.html      сайт для банкета — карточная тема
site/index-classic.html   он же в строгом темном оформлении, запасной вариант
worker/              прием ответов на RSVP в телеграм (не обязателен, см. ниже)
```

Две версии сайта содержат одно и то же и работают одинаково: `?g=`, RSVP,
вишлист. Отличается только оформление. Чтобы поменять местами:

```bash
cd site && mv index.html index-cards.html && mv index-classic.html index.html
```

Правки текстов придется вносить в обе, если держите обе. Проще выбрать одну и
вторую удалить.

---

## 1. Картинка на венчание

```bash
pip install playwright && playwright install chromium
cd card
python render.py --photo foto.jpg
```

Тексты правятся в словаре `TEXT` в начале `render.py`, верстка — в `card.html`.

Персональные картинки по гостям:

```bash
printf 'Дорогие Ивановы\nБабушка Люда\n' > guests.txt
python render.py --photo foto.jpg --guests guests.txt
```

Требования к фотографии: вертикальная, не слишком контрастная в нижней
трети — там лежит текст. Поверх фото лежит темная вуаль, так что светлый
кадр тоже подойдет.

Для мессенджеров: `--quality 90` дает JPEG поменьше. Для печати
подойдет увеличенный `device_scale_factor` в `render.py` (2 → A5 при 300 dpi).

## 2. Сайт для банкета

### Что заполнить

Все, что нужно заменить, помечено угловыми скобками `⟨…⟩`. Найти их:

```bash
grep -o '⟨[^⟩]*⟩' site/index.html | sort -u
```

Обязательный минимум: имя жениха, название и адрес храма, ссылки на карты,
время в расписании, дата дедлайна RSVP, ссылка на вишлист, телефон
и телеграм координатора, домен в `og:image`.

### Персональные ссылки

```bash
cd site
cat > guests.txt <<'EOF'
Анна и Петр; 2
Елена Юрьевна; 1
Семья Кузнецовых; 4
Егор
EOF
python make_links.py guests.txt --base https://ваш-домен
```

Получите `guests.json` (кладется рядом с `index.html`) и `links.csv` со
столбцами «Отправлено» и «Ответ» — удобно вести прямо в нем.

Скрипт можно запускать повторно: у гостей, которые уже есть в `guests.json`,
токен сохраняется, ссылки не ломаются.

Ссылка вида `?g=twe81u` подставляет обращение, префилл имени в форме и
ограничивает выбор числа мест. Быстрый вариант без файла:
`?n=Анна%20и%20Петр&s=2`.

**Важно про приватность:** `guests.json` лежит в открытом доступе. Кто угодно,
открыв `ваш-домен/guests.json`, увидит весь список гостей. Токены случайные,
перебрать чужую ссылку нельзя, но сам файл публичный. На 35 знакомых между
собой человек это обычно неважно — просто знайте. Если важно, можно вообще не
класть `guests.json` на сайт и рассылать ссылки в формате `?n=…&s=…`.

### Прием ответов

Три режима, переключаются в блоке `CONFIG` в конце `index.html`.

**А. Без бэкенда (сейчас включено).** Оставьте `rsvpEndpoint` пустым и укажите
свой телеграм в `fallbackTelegram`. Форма соберет ответ и откроет гостю готовое
сообщение в телеграме — ему остается нажать «отправить». Работает сразу, ноль
инфраструктуры. Минус: часть гостей не дожмет последнюю кнопку.

**Б. Телеграм-бот через воркер.** Разверните `worker/` (инструкция в шапке
файла, 5 минут, бесплатно), URL впишите в `rsvpEndpoint`. Ответы падают вам в
чат мгновенно, гость не уходит со страницы. Не забудьте поставить свой домен в
`ALLOWED_ORIGIN`.

**В. Яндекс Форма.** Если возиться не хочется вообще — уберите форму из
`index.html` и поставьте вместо нее ссылку или iframe на Яндекс Форму. Ответы
собираются в таблицу. Минус: гость уходит со страницы, персонализация теряется.

### Публикация

GitHub Pages — пошагово в `DEPLOY.md`. Workflow уже лежит в
`.github/workflows/pages.yml` и выкладывает только папку `site/`.

### Превью ссылки

Положите рядом `og.jpg` размером 1200×630 и пропишите полный URL в `og:image`.
Без этого ссылка в WhatsApp разворачивается серым прямоугольником, и часть
гостей на нее просто не нажмет. Проверить можно на opengraph.xyz.

### Шрифты

Prata, Spectral и Manrope грузятся с Google Fonts. Все три с кириллицей —
это редкость, большинство красивых свадебных гарнитур латиница-only. Если
хотите не зависеть от Google, скачайте woff2 через
`google-webfonts-helper`, положите в `site/fonts/` и замените `<link>` на
локальные `@font-face`. Резервный стек (Georgia) уже прописан, так что даже
при полном отвале шрифтов страница читается.

## Порядок действий

1. Заполнить `⟨…⟩` в `card/render.py` и `site/index.html`.
2. Выбрать фотографию, отрендерить картинку.
3. Выложить сайт, проверить с телефона — открыть свою же ссылку в WhatsApp.
4. Прогнать список гостей через `make_links.py`.
5. Разослать: картинку — кругу венчания, ссылку — тридцати пяти.
6. Через неделю написать тем, у кого в `links.csv` пусто в колонке «Ответ».

Дедлайн RSVP на странице стоит 25 сентября — поставьте свой, но сначала
уточните у Фермы Бенуа, за сколько дней им нужно финальное число гостей.
Ваш дедлайн должен быть на несколько дней раньше их.
