# Ответы анкеты в телеграм

Два способа. Разница в одном: кто нажимает «отправить».

---

## Способ А — за пять минут, без всего

Вписать свой ник в конце `site/index.html`:

```js
fallbackTelegram: "mariia_botkina"     // без @
```

Гость заполняет анкету, жмет «Отправить» — у него открывается телеграм
с уже готовым текстом:

```
RSVP · Семья Кузнецовых [w8dn4p]
Придут: 4
Автобус: да
Заметка: у ребенка аллергия на орехи
```

Ему остается нажать «отправить» в самом телеграме.

**Плюс:** ноль настройки, работает прямо сейчас.
**Минус:** последнюю кнопку жмет гость. Кто-то отвлечется и не дожмет,
и вы даже не узнаете, что он пытался ответить. На тридцати семи людях
это, скорее всего, двое-трое.

Ник нужен ваш личный, а не беседа: анкеты в общий чат сыпать неудобно.

---

## Способ Б — бот, ответы падают сами

Гость жмет «Отправить» — и все, сообщение уже у вас. Он никуда не уходит
со страницы.

Токен бота нельзя положить в сайт: его увидит любой, кто откроет исходный
код страницы, и сможет писать от имени бота. Поэтому нужна тонкая
прослойка — она лежит в `worker/`, разворачивается бесплатно.

### Что делать

**1. Завести бота.** В телеграме написать [@BotFather](https://t.me/BotFather),
команда `/newbot`, придумать имя. Он выдаст токен вида
`8123456789:AAF...` — это пароль, никому не показывать.

**2. Chat_id у вас уже есть** — тот, что с минусом. Минус означает группу,
то есть ответы будут видеть все ее участники, а не вы одна. Это удобно.

Две вещи про него:

- **Бот должен состоять в этой группе.** Добавьте его туда сразу после
  создания, иначе телеграм ответит `chat not found`.
- **Если группа когда-нибудь станет супергруппой** (это происходит само
  при некоторых действиях — например, при включении истории для новых
  участников), ее id поменяется на формат `-100…`, и анкеты молча
  перестанут приходить. Если ответы вдруг пропали — первым делом
  проверьте id заново через `getUpdates`.

Chat_id и токен вписывайте только через `wrangler secret` — не в файлы
репозитория. Репозиторий на GitHub Pages публичный, все, что в нем
лежит, видно всем.

**3. Развернуть прослойку.**

```bash
npm install -g wrangler
wrangler login
cd worker
wrangler deploy
wrangler secret put BOT_TOKEN     # вставить токен от BotFather
wrangler secret put CHAT_ID       # вставить ваш id группы, с минусом
```

Нужен аккаунт на cloudflare.com — бесплатный, регистрация по почте.

**4. Адрес уже вписан.** В `site/index.html` стоит

```js
rsvpEndpoint: "https://wedding-rsvp.sashaandmasha.workers.dev",
```

`ALLOWED_ORIGIN` в `worker/rsvp-worker.js` — `https://familysashaandmasha.github.io`.
Если поменяете домен сайта, прогоните `python3 configure.py <новый адрес>`
и передеплойте воркер.

**5. Проверить.** Открыть свою же персональную ссылку, отправить анкету,
убедиться, что сообщение пришло. Обязательно до рассылки.

---

## Что советую

Сделайте Б. Полчаса один раз против тридцати семи человек, которых
иначе придется догонять вручную. Способ А оставьте как запасной — он
и так включается сам, если воркер вдруг не ответит.
